# MindSpace Mobile

A Flutter app for daily journaling and mood tracking. It runs on Android and iOS (and web/desktop targets generated by Flutter).

## Features

- **Journal:** add, edit and delete entries; swipe to delete with a confirmation dialog.
- **Mood tracker:** pick a mood for the day and see your history.
- **Charts:** bar chart of mood counts (`fl_chart`) and a timeline of past moods.
- **Theming:** light and dark mode that follow the system, plus a settings screen with a colour picker (saved between launches).
- **Local storage:** entries are stored as JSON on the device with `shared_preferences`. No account, no server, no data leaves the phone.

## Project structure

```
lib/
  main.dart                 app entry, light/dark themes
  models/                   JournalEntry, MoodEntry (toJson / fromJson)
  screens/                  home (bottom navigation), journal, add/edit entry,
                            mood, mood history, settings
  theme/theme_controller.dart  persisted seed colour
  widgets/journal_card.dart
test/widget_test.dart       smoke test + model serialisation tests
```

## Run it

```bash
flutter pub get
flutter run          # pick an Android emulator/device or iOS simulator
flutter test
```

Requires Flutter with Dart SDK ^3.10.
